## 1. 단봇이란?

**단봇**은 단국대학교 학생들이 학사 정보를 빠르게 찾을 수 있도록 도와주는 AI 챗봇이에요.

- 수강신청 일정, 장학금 신청 방법, 셔틀버스 노선 등 학교 생활 전반의 정보를 제공해요
- 단국대 공식 홈페이지를 **실시간으로 검색**해서 항상 최신 정보를 알려드려요
- 모든 답변에 **원문 출처 링크**가 포함되어 직접 확인할 수 있어요

## 2. 시작하기

브라우저에서 아래 주소로 접속하세요.

```
http://localhost:7860
```

## 3. 화면 구성

```
┌──────────────────────────────────────┬─────────────┐
│  🐻 단봇 로고      [↺] [🌙] [⚙️]   │             │
├──────────────────────────────────────┤  우측 패널  │
│                                      │             │
│         채팅 영역                     │  📅 학사일정 │
│                                      │             │
│  🐻  무엇을 도와드릴까요?             │  🔗 바로가기 │
│                                      │             │
│  [FAQ 카드 버튼들]                    │  🔔 최신공지 │
│                                      │             │
├──────────────────────────────────────┤             │
│  입력창 [전송 버튼]                   │             │
└──────────────────────────────────────┴─────────────┘
```

### 헤더

| 버튼 | 기능 |
|---|---|
| 🐻 로고 | 단봇 아이콘 |
| ↺ 새로고침 아이콘 | 대화 초기화 (처음 화면으로 돌아가기) |
| 🌙 달 아이콘 | 다크모드 / 라이트모드 전환 |
| ⚙️ 설정 아이콘 | 설정 메뉴 |

### 우측 패널

- **학사일정** — 이번 달 주요 학사 일정을 한눈에 확인
- **바로가기** — 포털, 수강신청, 증명서 발급, 셔틀버스 노선 직접 이동
- **최신 공지** — 단국대 최신 공지사항 바로 확인

> 📱 모바일 환경에서는 우측 패널이 자동으로 숨겨져요.

## 4. 기능 사용법

### 4-1. FAQ 버튼으로 빠르게 질문하기

처음 접속하면 로고 아래에 자주 묻는 질문 버튼이 나타나요. 버튼을 누르면 바로 답변을 받을 수 있어요.

| 버튼 | 내용 |
|---|---|
| 📅 학사일정 | 이번 학기 주요 일정 안내 |
| 🎓 장학금 | 장학금 종류 및 신청 방법 |
| 🚌 셔틀버스 | 노선 및 운행 시간표 이미지 |
| 📝 수강신청 | 수강신청 일정 및 방법 |
| 📊 성적·졸업 | 성적 처리 및 졸업 요건 |
| 🏫 편의시설 | 식당, 도서관 등 시설 안내 |

### 4-2. 직접 질문하기

하단 입력창에 궁금한 내용을 자유롭게 입력하고 `Enter` 또는 전송 버튼을 눌러요.

```
예시)
- "2학기 수강신청 언제야?"
- "국가장학금 신청 기간 알려줘"
- "죽전캠 셔틀버스 몇 시에 출발해?"
- "성적 이의신청 어떻게 해?"
- "캠퍼스 지도 보여줘"
- "웅비홀 배치도 알려줘"
```

> 💡 답변을 기다리는 동안 입력창이 잠겨요. 답변이 완료되면 자동으로 다시 활성화돼요.

### 4-3. 이미지 응답 확인하기

셔틀버스, 캠퍼스 지도, 기숙사 안내처럼 이미지로 제공되는 정보는 채팅창에 이미지가 바로 표시돼요. 이미지를 클릭하면 크게 확대해서 볼 수 있어요.

```
이미지로 제공되는 정보)
- 🚌 셔틀버스 노선 및 시간표
- 🗺️ 죽전캠퍼스 종합 안내도
- 🏢 기숙사(웅비홀/진리관) 배치도
```

### 4-4. 출처 확인하기

AI 답변 아래에 **출처 카드**가 표시돼요. 카드를 클릭하면 단국대 공식 공지사항 원문을 바로 확인할 수 있어요.

```
┌──────────────────────────────────────┐
│ • 학사처 공식 공지사항                 │
│   dankook.ac.kr · 2025.06.20    ↗   │
└──────────────────────────────────────┘
```

### 4-5. 답변 복사하기

답변 말풍선에 마우스를 올리면 우측 상단에 복사 아이콘이 나타나요. 클릭하면 답변 내용이 클립보드에 복사돼요.

### 4-6. 대화 초기화

헤더 우측의 ↺ 버튼을 누르면 대화가 초기화되고 처음 화면으로 돌아가요.

### 4-7. 다크모드

헤더 우측의 🌙 버튼을 눌러 다크모드로 전환할 수 있어요. 다시 누르면 라이트모드로 돌아와요.

## 5. 질문 잘하는 법

단봇은 자연어를 이해하기 때문에 평소 말하듯 질문해도 괜찮아요. 하지만 아래 팁을 참고하면 더 정확한 답변을 받을 수 있어요.

### ✅ 이렇게 물어보세요

```
"2025년 2학기 수강신청 일정이 언제야?"
"국가장학금 1유형 신청 방법 알려줘"
"죽전캠 셔틀버스 토요일 시간표 있어?"
"복수전공 신청 기간이 언제야?"
"캠퍼스 지도 보여줘"
```

### ❌ 이런 질문은 답변이 어려울 수 있어요

```
"수업 들어도 돼?"          → 너무 모호한 질문
"교수님 연락처 알려줘"      → 개인정보는 제공하지 않아요
"내 성적 얼마야?"          → 개인 학적 데이터는 접근 불가
```

## 6. 자주 묻는 질문 FAQ

**Q. 단봇이 틀린 정보를 알려주면 어떻게 하나요?**

A. 답변 아래 출처 카드를 클릭해서 원문을 직접 확인해주세요. 오류가 발견되면 [문의 및 피드백](#7-문의-및-피드백) 섹션을 통해 알려주시면 빠르게 개선할게요.

**Q. 질문이 인터넷에 저장되나요?**

A. 아니요! 단봇은 로컬 서버에서 운영되기 때문에 질문 내용이 외부로 전송되거나 저장되지 않아요.

**Q. 어떤 정보까지 알려줄 수 있나요?**

A. 단국대 공식 홈페이지에 공개된 정보라면 대부분 답변할 수 있어요. 개인 학적 정보나 비공개 데이터는 제공하지 않아요.

**Q. 모바일에서도 사용할 수 있나요?**

A. 네, 모바일 브라우저에서도 접속 가능해요. 모바일 환경에서는 우측 정보 패널이 자동으로 숨겨지고 채팅 화면에 최적화된 레이아웃으로 표시돼요.

**Q. 답변이 너무 느려요.**

A. 단봇은 실시간으로 홈페이지를 검색하고 AI가 답변을 생성하기 때문에 최대 30초 정도 소요될 수 있어요. 셔틀버스, 지도, 기숙사 안내는 이미지로 즉시 제공돼요.

**Q. 오류 메시지가 떴어요.**

A. 빨간색 말풍선으로 오류 안내가 표시되면 잠시 후 다시 시도해주세요. 문제가 지속되면 아래 문의처로 연락해주세요.
