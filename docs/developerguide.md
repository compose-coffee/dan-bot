## Developer Guide : Dan-bot

## 프로젝트 개요
본 프로젝트는 단국대학교 재학생 및 교내 구성원들의 학사 정보, 교내 편의 시설, 캠퍼스별 셔틀버스 운행 시간 등에 대한 정보 접근성을 향상하기 위해 개발된 텍스트 기반의 학사 맞춤형 인공지능 챗봇 서비스이다. 기존의 통상적인 대학 안내 시스템이 텍스트 위주의 단순 링크 나열 형식이거나 고정된 규칙 기반 시나리오 챗봇에 의존하여 사용자의 자연어 질의에 유연하게 대응하지 못하는 한계를 극복하고자 기획 및 구현되었다. 본 프로젝트는 오픈소스 기반의 로컬 거대 언어 모델 관리 프레임워크인 Ollama AI 인프라와 검색 증강 생성(RAG) 기술을 융합하여 단국대학교 맞춤형 지식 베이스를 기반으로 정교하고 안전한 답변을 제공하는 것을 목적으로 한다.

## 사전준비
- **Python 3.12 이상 필요**
- git
- **Ollama AI 로컬 인프라 및 가상화 환경 구축 필요 (Llama 3.2 모델 가동)**
- **Selenium 동적 크롤링용 Chrome 브라우저 및 WebDriver 환경 매핑 필요**

## 주요 디렉토리와 파일 구성 설명 :
- assets : README 및 기술 문서에 연동되는 이미지 자산, 시스템 로고, 구조 시각화 UML 다이어그램 보관 폴더
- docs : 시스템의 유지보수와 사용성 확보를 위한 가이드라인 명세 폴더
  - `UserGuide.md`: 일반 사용자를 위한 챗봇 인터페이스 조작법 및 기능 안내 매뉴얼
  - `DeveloperGuide.md`: 시스템 아키텍처, 모듈별 역할 및 개발 사양이 명시된 본 명세 가이드라인 문서
- crawler : 단국대학교 공식 웹사이트 정보 수집 및 전처리 모듈 디렉터리
  - `scraper.py`: Selenium WebDriver 엔진을 활용해 자바스크립트 동적 렌더링 요소를 추적하고 공지사항 및 테이블 마크업을 정제 텍스트로 덤프하는 소스 스크립트
- ai_engine : 로컬 RAG 기반 지식 제어 및 Ollama 모델 추론 연산 통제 핵심 서비스 로직 디렉터리
  - `llm_handler.py`: Ollama 호스트 API 세션 연동 및 할루시네이션(환각) 차단용 시스템 가이드라인 프롬프트 주입 제어 스크립트
  - `rag_logic.py`: 수집된 비정형 도큐먼트 텍스트 소스를 토큰 범위 내 청크로 분할하고 유저 질의와 연관성이 높은 컨텍스트 문서를 추출하여 프롬프트 영역으로 연동하는 요약 로직 스크립트
- static : 사용자의 채팅 UI 인터페이스에 시각 자료로 렌더링되는 웹 스타일시트, 자바스크립트 및 캠퍼스맵, 셔틀 가이드 이미지 파일 저장 위치
- templates : 사용자가 대화를 주고받을 수 있는 비동기 대화창 화면을 렌더링하는 `index.html` 템플릿 보관 폴더
- app.py : 클라이언트 요청 라우팅, 자연어 입력 접수, 모듈별 데이터 흐름 제어 및 통합 연산을 관장하는 Flask 메인 백엔드 엔트리 포인트 웹 서버 구동 파일
- tests : 코드 안전성 검증을 위한 단위 테스트(Unit Test) 스크립트 및 RAG 응답 데이터 정합성 검증용 성능 평가 코드 보관 폴더

## 각 파일들의 핵심 처리 :

### app.py
- **역할**:
  - 웹 기반 프론트엔드 채팅 UI 인터페이스와 연동되는 메인 웹 서버 및 라우팅 허브 전담
  - 클라이언트가 입력한 비정형 자연어 질문을 접수한 후 의도 분석, 크롤링 트리거, RAG 연동, 최종 추론 요청까지의 파이프라인 제어 스케줄러 기능 수행
- **핵심 함수**:
- `index()`
  - 메인 채팅 인터페이스 페이지인 `templates/index.html`을 사용자 브라우저 화면에 렌더링하는 라우트 함수
- `ask_handler()`
  - 사용자가 대화창에 입력한 문자열 메시지를 POST 비동기 방식으로 접수하는 API 엔드포인트 함수
  - 질문 내 핵심 키워드를 식별하여 단순 고정 매핑 처리가 가능한 정적 자원(`src/static/` 내 이미지) 표기 여부 판단 및 `url_map` 문자열 대조 알고리즘 수행
  - 실시간 정보 연동이 전제될 경우 `scraper.py`를 호출하고, 가공된 데이터를 `rag_logic.py` 및 `llm_handler.py`로 순차 이식하여 최종 정제된 JSON 데이터를 프론트엔드로 반환

### crawler/scraper.py
- **역할**:
  - 교내 데이터 연동 공식 API의 부재를 극복하기 위해 단국대학교 공식 홈페이지 내부 구조를 추적하는 동적 스크래핑 제어 전담
  - BeautifulSoup의 정적 마크업 파싱 한계를 극복하고 자바스크립트로 동적 렌더링되는 학사 공지, 장학 규정, 셔틀버스 테이블 요소를 추출하기 위해 Selenium WebDriver 엔진 탑재
- **핵심 함수**:
- `fetch_university_notice(target_url: str) -> str`
  - 지정된 단국대학교 공식 웹사이트 타깃 페이지로 세션을 열어 브라우저를 백그라운드(Headless) 환경에서 자동 조작
  - 데이터 통신 지연에 대응하기 위해 타깃 엘리먼트 가시성이 확보될 때까지 명시적 대기(Explicit Wait) 매커니즘을 적용하여 안정성 보장
  - 웹페이지 본문 내부의 불필요한 스크립트, css 태그 엘리먼트를 원천 소거하고 알맹이 텍스트 소스만을 전처리 덤프하여 반환
- **주요 구현**:
  - 데이터 경로 탐색 오류 및 웹 서버 다운 현상에 견고하게 유연대응할 수 있도록 스크래핑 연산 전반 및 예외 조건 처리 구간에 `try-except` 예외 차단 블록을 마감 구현

### ai_engine/rag_logic.py
- **역할**:
  - `scraper.py`에서 전달받은 원천 비정형 도큐먼트 데이터를 언어 모델이 오염 없이 수용할 수 있도록 정렬하는 RAG 파이프라인 최적화 전담
  - 긴 문장의 데이터를 토큰 제한 범위에 맞춰 슬라이싱하고, 정보 유실 및 문맥 단절을 원천 방지하기 위해 일정 오버랩(Overlap) 버퍼를 두는 슬라이딩 윈도우 알고리즘 수행
- **핵심 함수**:
- `segment_and_align_context(raw_text: str, user_query: str) -> str`
  - 스크랩 완료된 단국대 웹 원천 도큐먼트 소스를 일정한 크기의 텍스트 문서 청크 블록 단위로 슬라이싱 처리
  - 사용자가 입력한 자연어 질의어와의 문맥적 유사성 가중치를 측정 및 분석하여 가장 관련도가 높은 단국대 도메인 특화 컨텍스트 블록 문서 후보군을 선별 및 정렬하여 시스템 가이드라인 프롬프트 확장 자원으로 변환

### ai_engine/llm_handler.py
- **역할**:
  - 외부 클라우드 API 연동 종속을 탈피하고 학생 질의 데이터 보안을 유지하기 위해 오픈소스 로컬 LLM 서빙 프레임워크 Ollama 자원 연동 전담
  - 대형 모델의 고질적 한계점인 할루시네이션(환각) 현상을 방지하기 위한 시스템 프롬프트 가이드라인 설계 및 세션 제어
- **핵심 함수**:
- `request_local_inference(context_block: str, query: str) -> str`
  - `rag_logic.py`에서 선별 정리한 단국대학교 지식 문서 컨텍스트 블록과 사용자의 자연어 질문을 조합하여 확장 프롬프트 생성
  - "반드시 제공된 단국대학교 컨텍스트 문서 데이터 내부에서만 팩트 기반 답변을 도출하고, 명시되지 않은 애매한 학사 정보에 대해서는 무작위로 지어내지 말고 모른다고 명확히 답변하라"는 제어 명령을 프롬프트 레벨에 강력 주입하여 출력 무결성 확보
  - 하드웨어 GPU VRAM(비디오 전용 메모리) 인프라 용량 한계를 초과하여 발생하는 하드웨어 스와핑 병목을 차단하기 위해 가중치를 4비트 수준으로 압축한 양자화(Quantized) 모델 파라미터를 메모리에 상주시켜 안정적인 실시간 추론 연산 통제 수행

## 모델 학습방법 및 모델 파인튜닝 방법 :

### 모델 학습방법
- **로컬 RAG 도메인 지식 최적화 학습**
  1. 단국대학교 공식 웹사이트 학사 공지사항, 생활관 장학 규정집 가이드라인 등에서 추출한 정제 코퍼스 문장셋 데이터를 수집하여 지식 베이스 아카이빙 단계를 거친다.
  2. 로컬 서버 엔진 내부의 가속 연산 스크립트 환경에서 RAG 임베딩 빌더 파이프라인 및 문서 탐색 알고리즘을 구동한다.
  3. 왜곡 없는 팩트 데이터 매칭 성능을 모니터링하기 위해 오차 추이를 지속 추적하며 최적의 슬라이딩 윈도우 분할 청크 및 오버랩 최적 파라미터 세팅값을 도출한다.
  4. 순차 탐색 복잡도를 최소화하기 위해 키워드 토큰화 기반 역색인 매칭 검증 연산을 완료할 때까지 학습 및 셋업 프로세스를 대기한다.

### 모델 파인튜닝방법
- **하드웨어 최적화 양자화 공정**
  1. 제한된 로컬 하드웨어 리소스 사양 내에서 Llama 3.2 오픈소스 경량 거대 언어 모델의 추론 Throughput 속도를 극대화하고 메모리 병목을 극복하기 위해 미세 조정 양자화 파이프라인을 기동한다.
  2. 원본 Llama 3.2 모델의 파라미터 규격을 타깃 인프라 사양으로 설정한다.
  3. 로컬 그래픽 자원의 VRAM 용량을 초과하여 대역폭 정체가 유발되는 현상을 원천 방지하기 위한 파라미터 다운사이징 압축 미세 조정을 수행한다.
  4. 모델 가중치 정밀도를 4비트(4-bit Quantization) 수준으로 긴밀하게 다듬는 미세 조정을 통과시켜 최종 결과물을 로컬 Ollama 호스트 서빙 디먼 인프라 영역에 완전히 안착시킨다.

### 데이터셋
- **단국대학교 맞춤형 지식 베이스 데이터셋**
  - 단국대학교 공식 홈페이지 학사 가이드, 장학금 지급 규정 및 생활관 입사 안내 원천 도큐먼트 데이터셋
  - 교내 죽전 및 천안 캠퍼스별 편의 시설 정보, 건물 일련번호 매핑 및 정적 위치 바인딩 테이블 데이터
  - 캠퍼스별 공식 셔틀버스 운행 시간표, 정류장 명칭 및 학사 공지사항 동적 텍스트 덤프 데이터
  - 할루시네이션 교정 및 컨텍스트 매칭 검증을 위해 수작업으로 정밀 가공을 완료한 단국대 특화 자연어 질의응답 시나리오 데이터셋

## 기타 설명
- **3-Tier 구조 기반의 함수형 모듈화 아키텍처**
  - 본 시스템은 유지보수 효율성 및 기능적 결합도 제어를 위해 단일 파일 스크립트 집약 구조를 전면 배제하였다.
  - 웹 서비스 인터페이스 계층(`src/app.py`), 웹 크롤러 데이터 수집 계층(`src/crawler/`), AI/RAG 엔진 가속 계층(`src/ai_engine/`)으로 디렉터리 구조를 엄격하게 파티셔닝하여 레이어 간 데이터 간섭 및 연산 충돌 현상을 사전에 전면 방지하도록 설계되었다.
- **Privacy-First 인메모리 데이터 보안**
  - 단국대학교 학생들이 입력하는 비정형 자연어 질의 데이터 로그 및 동적 수집된 대학 정보 파이프라인은 상용 클라우드 AI 인프라와 외부 기업 서버로 일체 전송되지 않는다. 오직 로컬 단독 서버 엔진 내부의 인메모리 영역에서 캡슐화되어 폐쇄적으로 추론 및 처리되므로 최고 등급의 학사 정보 보안 환경을 보장한다.

## 참고 유의사항
- **하드웨어 및 소프트웨어 파이프라인 병목 구조 (컴퓨터 아키텍처적 관점)**
  - 본 시스템은 자원이 한정된 로컬 서버 환경에서 거대 언어 모델 연산을 상시 가동해야 하므로 프로세서 아키텍처 및 하드웨어 가속 성능 최적화 구조에 직접적인 영향을 받는다.
  - 중앙 처리 장치 연산 시 명령어 간의 타이밍 충돌 및 자원 의존성 문제로 파이프라인 일시 정체(Stall)가 유발되는 **5-stage pipelined** 아키텍처의 **Data Hazard** 현상과 기계적으로 유사하게, 로컬 RAG 시스템 역시 순차적인 Selenium 동적 크롤링 수집 과정과 로컬 VRAM 기반 임베딩 추론 연산 과정이 동기식으로 교차 구동될 때 전체적인 데이터 흐름의 파이프라인 정체 및 단위 시간당 처리량(Throughput) 저하 현상이 유발될 수 있는 잠재적 한계가 관찰되었다.
- **공학적 해결 방안 및 시스템 개선 방향**
  - 물리적 하드웨어 한계로 발생하는 추론 지연 현상을 최소화하기 위해, 4비트 양자화 처리가 완료된 Llama 3.2 모델 가중치 바이너리를 GPU VRAM 상주 영역에 완전히 고정 안착시켜 연산 파이프라인 중첩 시 발생하는 자원 충돌 및 오버헤드를 1차적으로 제어 방지하였다.
  - 향후 시스템 고도화 단계에서는 동기식 순차 데이터 크롤링 전처리 수집 메커니즘을 비동기식 멀티스레딩 병렬 파이프라이닝 기법으로 개편하고, `src/app.py` 라우팅 레이어 내부에 자주 인입되는 단국대 빈출 학사 질의 항목에 대응하는 인메모리 캐싱(Caching) 레이어를 추가 이식하여 물리적 연산 오버헤드를 제어하고 추론 응답 지연 시간을 혁신적으로 단축해야 하는 보완 방향성이 존재한다.
- **AI 도구 활용 및 무결성 명시 사항**
  - 본 시스템은 상용 인프라 외부 유출 리스크를 완전히 헤지하기 위해 Ollama AI 오픈소스 프레임워크를 독자 빌드하여 Llama 3.2 모델을 로컬 환경 내부에서 구동하고 있다. 프롬프트 인젝션 가이드라인을 엄격히 조율하여 할루시네이션을 전면 제어하고 있으며, 오직 실시간 동적 스크래핑으로 확보한 단국대 홈페이지 정보 팩트 범위 내에서만 답변을 구조화하도록 정확도 100% 신뢰성 검증 파라미터 세팅을 엄밀하게 유지하고 있다.
